# Logistics Dashboard Android App

تطبيق أندرويد بسيط للتعامل مع API الـ Logistics Backoffice (Talabat / Delivery Hero)

## المميزات
- حفظ الـ Access Token و Refresh Token
- إضافة الـ Bearer Token تلقائياً لكل Request
- التعامل مع خطأ 401 (التوكن انتهى)
- جلب قائمة الـ Riders حسب المدينة

## التقنيات
- Kotlin
- Retrofit + OkHttp
- Coroutines
- SharedPreferences

## طريقة الاستخدام
1. افتح المشروع في Android Studio
2. حط الـ Token بتاعك
3. شغّل التطبيق
